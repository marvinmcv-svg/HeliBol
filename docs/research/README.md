# Competitive research — how 21st.dev, Mobbin, Awwwards & the motion libraries are built

Research behind kinetik 2.0. **kinetik 2.2** (three.js collection, MotionSites, unlumen UI, 21st UI gaps, GSAP round 2) is documented in [`sources-2.2.md`](sources-2.2.md). Raw data lives next to this file:

- `catalogs.json` — every component name in each open-source library's catalog (extracted from their source), plus 21st.dev's full category taxonomy with item counts.
- `rea/summary.json` — REA static-analysis results for each codebase (generated by `rea/summarize_rea.py`).
- `rea/summarize_rea.py` — turns REA Evidence files into the summary.

## Method

**REA (Reverse Engineer Anything, [morluto/rea](https://github.com/morluto/rea), `rea-agents@6.8.0`)** was used in two ways:

1. **Static JavaScript analysis** of each open-source codebase:
   ```bash
   rea analyze-javascript-application <repo> --json > <name>.json   # full Evidence (37–162 MB each)
   python3 docs/research/rea/summarize_rea.py *.json > summary.json
   ```
   REA builds an application graph (modules, imports, endpoints, client storage), a semantic graph and a route inventory, each with authenticated Evidence IDs.
2. **Thumbnail capture.** Every gallery thumbnail on the site is a `rea capture-web-screenshot` over a Chrome DevTools connection (`scripts/capture-thumbs.mjs`). Each capture's REA `evidence_id` and PNG sha256 are kept in `apps/docs/public/thumbs/manifest.json`.

**Network limits.** This environment's network policy blocks `21st.dev`, `mobbin.com`, `awwwards.com`, `refero.design`, `magicui.design`, `ui.aceternity.com`, `reactbits.dev` and `motion-primitives.com` (direct and via fetch). GitHub was reachable, so the libraries were studied from their **open-source repositories** — including 21st.dev's own site code (`serafimcloud/21st`). Mobbin, Awwwards, Refero and Aceternity are closed-source, so notes on them come from web-search results (sources at the end). Allowing those hosts in the environment's network settings would let REA's `capture-browser-scenario` / `analyze-web-bundle` inspect the live sites.

**Rule.** Libraries were studied for catalog breadth, taxonomy and engine choices only. Every kinetik component is written from scratch (see `CREDITS.md`). React Bits is MIT + Commons Clause; nothing was copied from it or anything else.

| Codebase | JS/TS files parsed | AST nodes | Findings | Routes recovered | Motion-engine import edges |
|---|---:|---:|---:|---:|---|
| 21st.dev (site) | 516 | 316k | 5,839 | 104 | Motion 32, Radix/shadcn 48 |
| Magic UI | 363 | 135k | 3,560 | 98 | Motion 51, canvas/WebGL 14 |
| React Bits | 2,263 | 4.26M | 13,630 | 5 | three/OGL 25, Motion 20, GSAP 5 |
| Motion Primitives | 173 | 45k | 1,566 | 36 | Motion 192 |
| Cult UI | 561 | 483k | 6,868 | 158 | Motion 32 |
| Animata | 618 | 189k | 4,332 | 65 | Motion 123, canvas 5 |
| Fancy Components | 224 | 84k | 2,221 | 54 | Motion 272, canvas/physics 22, Lenis 4 |

What this says about engines:

- **Motion (framer-motion) is the default** across every library. Fancy and Motion Primitives use almost nothing else. This matches our engine decision tree.
- **GSAP is rare** (React Bits only). That leaves room for kinetik's GSAP pieces: SplitText, ScrollTrigger, DrawSVG.
- **WebGL/canvas is where the "wow" backgrounds come from.** React Bits uses three/OGL, Magic UI uses cobe/confetti, Fancy uses matter-js. kinetik 2.0 adds a shared `useCanvas` hook and 9 canvas/WebGL pieces, with no three.js except the R3F shell.
- **Nobody ships reduced-motion fallbacks systematically.** It is our clearest differentiator, enforced by the test suite.

## 21st.dev — product surface (from REA's route inventory of its code)

REA recovered 104 routes. Grouped:

- **Browse:** `/` · `/s/<tag>` (58 category pages) · `/q/<query>` search · `/c/<collection>` collections · `/templates`
- **Item pages:** `/<username>` · `/<username>/<component>` · `/<username>/<component>/<demo>` — author-first URLs; one component can have several demos.
- **Creation:** `/publish`, `/publish/demo`, `/publish/template`, `/import`, `/studio/<user>` (analytics, bundles, monetization, sandbox)
- **AI:** `/magic`, `/magic-chat`, `/magic/console`, `/magic/onboarding`, plus an `/api/prompts` endpoint; prompt rules at `/settings/rules`
- **Community:** `/contest`, `/contest/leaderboard`, `/contest/archive/<week>`
- **Money:** `/pricing`, `/subscription`, Stripe checkout endpoints (`create-checkout`, `create-checkout-bundle`), `/settings/payouts`

Other patterns REA surfaced:

- **List parameters:** `sortBy`, `sortOrder`, `period` (trending window), `page`, `pageSize`, `search`, `saved_sort_by`.
- **Persisted install preference:** `localStorage` key `preferredPackageManager` (npm / pnpm / yarn / bun tabs).
- **Gallery cards are a static image thumbnail that swaps to a video on hover** (`card-image.tsx` + `card-video.tsx`, with a load cache). kinetik adopts this, but swaps to the *live demo* instead of a video.

**Taxonomy** (from `lib/navigation.ts`): 19 marketing sections (433 demos) and 39 UI sections (1,035 demos). Largest: Buttons 130, Inputs 102, Cards 79, Heroes 73, Selects 62, Texts 58, Sliders 45, Accordions 40, Tabs 38, Dialogs 37, Features 36, Calls to Action 34, Calendars 34, Backgrounds 33, AI Chats 30, Tables 30.

## GSAP Demo Hub (scraped with Firecrawl)

`demos.gsap.com` was reachable through Firecrawl, unlike the hosts above. Its `sitemap.xml` lists **~80 demos**; the 13 category pages (Buttons, Cursor, Galleries & Media, Hover, Loaders, Navigation, Scroll, Sliders, Text, Page Transitions, UI, WebGL, Fun) and 16 plugin pages give the taxonomy. Each demo page carries a title, tags, a "How it works" note and the core logic. Full catalog + the demo → kinetik mapping: [`gsap-demos.json`](gsap-demos.json).

What it showed:

- **Scroll is GSAP's biggest category (20 demos)**: velocity skew, scrubbed Flip bento, batch reveals, image sequences, mask-on-scroll, waypoints/indicators, bouncing footer, Observer-driven looping panels.
- **Flip is the layout workhorse**: filtering, grid ↔ list, grid → modal, carousels.
- **Plugins are now free**, so MorphSVG, DrawSVG, Physics2D, Inertia, CustomWiggle and SplitText are fair game for a copy-paste library.
- **Newest pattern: `easeReverse`**, a different ease on the way back, so exits feel crisp instead of replaying a bounce backwards.

kinetik had only 5 GSAP components, so this round adds **29 GSAP components**: one per technique not already covered, all written from scratch (no GSAP demo code or media copied). The **GSAP collection** (`/components?engine=gsap`) groups them.

The [GSAP Showcase](https://gsap.com/showcase/) (Site of the Day/Week winners) filters by Scroll Animation, Text Animation, SVG Animation, UI Interactions, WebGL, Three.js and, notably, **Reduced Motion**. That supports kinetik's reduced-motion-everywhere rule.

**Bug found along the way:** scroll demos in preview frames were binding their ScrollTriggers to `window` because the demo scroller's ref is attached after children's layout effects. `DemoScroller` now mounts children only once its element exists, which fixed every scroll demo, old and new.

## Closed platforms (from search)

- **Mobbin** browses by **Screens, UI Elements and Flows**. Category chips include Checkout, Settings, Login, Subscription & Paywall, Account Setup and Welcome. Flows cover whole journeys, including error states. It also has text-in-screenshot search, prototype mode and copy-to-Figma. Reported size: roughly 600k screens from ~1,150 apps.
- **Refero** tags every screen by **page type** (e.g. Dashboard, Settings, Paywall & Subscription), **UX pattern** (testimonials, filters, billing…) and **UI element** (Button, Table, Modal, Switch…), plus flows, fonts and industry. It has an MCP data model for agents.
- **Awwwards** judges on Design (~40%), Usability (~30%), Creativity (~20%) and Content (~10%), with a separate Mobile Excellence track. Commentators note that most submissions lose on usability, often on missing focus states and reduced-motion handling.
- **Aceternity UI** is known for cinematic marketing effects: 3D card, lamp header, wavy background, hero parallax, container scroll. It is distributed through the shadcn registry, and part of its catalog is paid (Pro).

## Gap analysis → what kinetik 2.0 added

| Gap found | Added in 2.0 |
|---|---|
| No standalone **heroes** (21st's biggest marketing category) | 8 heroes: mesh + floating cards, video dialog, floating gallery, scroll tilt, editorial, dev terminal, dotted globe, spotlight grid |
| No **AI interfaces** (21st "AI Chats", marked new) | 8 AI components + an AI chat app block: prompt box, thinking steps, streaming chat, voice orb, voice wave, suggestions, code stream, agent timeline |
| Text effects were thin vs React Bits / Animata / Fancy | +14: morph, circular, 3D flip, velocity marquee, wave, glitch, letter roll, split-flap, sparkles, variable proximity, falling letters, line loop, stroke draw, odometer |
| Backgrounds lacked canvas/WebGL depth | +14 incl. particles network, warp starfield, waves, dot glow, raw WebGL shader, lamp, retro grid, boxes, beams |
| No **widgets** (Animata) or **device mockups** (Magic UI) | 11 widgets + 4 mockups |
| Product UI (21st UI sections: selects, inputs, sliders, menus, popovers) | select, tag input, elastic slider, search expand, dropzone, context menu, hover card, command palette, morphing popover, mega menu, sidebar, bottom bar, speed dial |
| Cards & cursor effects | +14 cards (holo foil, swipe deck, 3D layers, pixel dissolve, folder…) and +6 cursors (custom, image trail, click spark, blob, eyes, crosshair) |
| Mobbin flows: only 6 | +6 flows: messaging, stories, expanding music player, ride booking sheet, fly-to-cart food order, guided breathing |
| Refero page types missing (AI app, settings, product, blog) | +10 blocks: AI chat app, settings page, product page, blog grid, changelog, testimonials wall, integrations orbit, footer reveal, stats, contact |
| Cards rendered live → slow, "empty" spinners | REA-captured thumbnails; live demo mounts on hover (21st pattern) |

**Still missing (roadmap):** 21st-style author pages and collections · sort by trending/period · a package-manager install-tab preference · tables, calendars/date pickers, radio groups and pagination (21st UI sections) · Mobbin-style error/empty-state flows · Rive/Lottie players · the native Expo gallery · an MCP server.
