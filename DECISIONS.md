# DECISIONS

Decisions made while executing `motion-library-master-plan.md`. Per Section 0.9, ambiguities were resolved toward (a) accessibility, (b) smaller bundles, (c) platform-native feel.

| # | Decision | Why |
|---|---|---|
| 1 | **Versions verified at build time:** Next 16.4, React 19.3, Motion 14.7 (plan said v13), GSAP 3.15 (all plugins free), Lenis 1.3, Tailwind 4.3, three r186 / R3F 9 / drei 10, TypeScript 5.9. | Plan rule: always use latest stable. TypeScript 7 (native port) skipped — Next's type-check pipeline targets the TS 5 API. |
| 2 | **pnpm workspaces + Turborepo**, packages `tokens`, `core`, `web`; app `docs`. | Matches Section 4.2. Blocks and flows live in `apps/docs/{blocks,flows}` because they are docs-composed sections. |
| 3 | **Registry JSON is generated by `scripts/gen-registry.mjs`** (shadcn `registry-item` schema, content inlined) instead of `shadcn build`. | One script also emits the gallery index, prompts and content files; no extra build step. Output is schema-compatible with `npx shadcn add <url>`. |
| 4 | **Imports rewritten on publish:** `@kinetik/core` → `@/lib/kinetik/core`, `@kinetik/core/utils` → `@/lib/kinetik/utils`, `@kinetik/tokens` → `@/lib/kinetik/tokens`, `@web/<cat>/<slug>/<slug>` → `@/components/kinetik/<slug>`. | Components are developed in a monorepo but land in users' repos at shadcn-conventional paths. |
| 5 | **`cn` split into `core/utils.ts`** (no `"use client"`). | CSS-only components stay Server Components (0 KB JS) yet share `cn`. |
| 6 | **Component CSS ships inside the component** via React 19 `<style href precedence>` (hoisted + deduped). | Copy-paste stays one file; no global stylesheet edits needed for keyframes or `@property`. |
| 7 | **Reduced motion = OS setting OR `<html data-reduce-motion>`** (`useReducedMotion` in core). Docs toggle sets the attribute; the docs `motion-reduce:` Tailwind variant is extended to match it. | Lets the docs preview fallbacks (Section 5.5) and lets apps offer an in-app setting. |
| 8 | **Pinned scroll sections use native `position: sticky`** with GSAP ScrollTrigger (or Motion `useScroll`) only scrubbing transforms; heights use `cqh` units. | ScrollTrigger pin-spacing breaks inside nested scrollers (preview frames, modals). Sticky + `cqh` works in both window and contained scrollers. |
| 9 | **`text-scroll-highlight` uses Motion `useScroll`** instead of CSS `view()` timelines. | Per-word ranges need container support across browsers; Firefox scroll-timeline support still varies. `scroll-reveal` and `scroll-progress` do use CSS scroll-driven animations with fallbacks. |
| 10 | **Dialog built on native `<dialog>` + `@starting-style`** rather than Radix. | Free focus trap, Esc, inert background and top-layer; exit animation via `transition-behavior: allow-discrete`; zero JS animation. |
| 11 | **3D demo uses local `Lightformer`s, not an HDR preset.** | drei presets download HDRs from a CDN at runtime (blocked offline / CSP); local lighting has no network dependency. WebGL by default; WebGPU left for Phase 8. |
| 12 | **Demo imagery is procedurally generated** (`scripts/gen-demo-images.mjs`, rendered with headless Chromium). | License-free, offline, consistent art direction; no hotlinking. |
| 13 | **Mobile (Section 8) delivered first as interactive web prototypes in a phone frame** (`/flows`) whose AI prompts target Expo SDK 55 + Reanimated 4 + Gesture Handler + expo-haptics with identical spring presets. | Lets every flow be previewed in the browser like Mobbin, while the prompt produces native code. A full Expo gallery app is the next phase (see PROGRESS). |
| 14 | **Toggle switch, tabs and indicators use Motion `layout`/`layoutId`** scoped with `useId`/`LayoutGroup`. | Multiple instances on one page (galleries, flow strips) must not share layout IDs. |
| 15 | **Tests:** one Vitest contract suite renders every demo in normal and reduced-motion modes and validates every meta (426 tests). | Catches contract drift and reduced-motion crashes (it found one in `text-scroll-highlight`). WebGL is excluded from jsdom. |
| 16 | **Lucide brand icons replaced** (GitHub/Slack removed upstream). | Use neutral icons in demos. |
